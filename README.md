# Malayalam Neo

Учить малаялам по фразам и манглишу: 255 уроков, 2500 фраз, 12 юнитов,
озвучка, транскрипция и профиль со статистикой.

## Открыть

- Приложение: [malayalam-neo.vercel.app](https://malayalam-neo.vercel.app)
- Telegram-бот: [@KeralaFood_bot](https://t.me/KeralaFood_bot)

## Про этот репозиторий

Здесь осталась только короткая страница-ссылка для GitHub Pages.
Само приложение живёт на Vercel; исходники — в основном проекте
`Malayalam_Neo_App` (Next.js + общий движок уроков).

Старая статическая версия на 60 фраз удалена, её история сохранена в git.

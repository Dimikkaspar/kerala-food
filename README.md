# Malayalam Learning WebApp

## Описание

Приложение для изучения малаяламского языка с помощью фраз и манглиша.

## Функции

- Выбор языка: русский, английский, малаялам
- Случайные фразы с манглишем, малаяламским письмом и переводом
- Синтез речи для малаяламских фраз
- Интуитивно понятный интерфейс
